# Newsletter Summarizer

This repository contains an application that reads newsletters received by email and applies AI to summarize them by topics.

## Purpose and Goals

The purpose of this repository is to provide a tool that helps users manage and digest their email newsletters more efficiently. By summarizing the content of newsletters, users can quickly get an overview of the topics covered and decide which ones to read in detail.

## Setup Instructions

To set up the project locally, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/noreuzis/ghworkspace_test.git
   ```
2. Navigate to the project directory:
   ```
   cd ghworkspace_test
   ```
3. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

## Usage Examples

To run the application, use the following command:
```
python app.py
```

## Dependencies and Prerequisites

- Python 3.6 or higher
- Required Python packages (listed in `requirements.txt`)
- An email account with IMAP access
